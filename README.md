TemplatePilot is a lightweight Windows desktop application for managing and inserting reusable text snippets.

Whether you're handling IT support tickets, writing repetitive emails, documenting procedures, or reusing frequently needed instructions, TemplatePilot helps you save time and keep your responses consistent.

Organize your snippets into categories, open the searchable popup with a global keyboard shortcut, and insert the selected content into your current application.

## ✨ Features

- **⌨️ Global hotkey** — Access your snippets from other applications using a customizable keyboard shortcut.
- **📁 Categories & search** — Organize, manage, and quickly find reusable text snippets.
- **📝 Rich content** — Support for plain text, formatted text (HTML/RTF), and clipboard images.
- **👁️ Live preview** — Preview snippets before inserting them, with a resizable pane positioned to the right or below.
- **🎨 Customizable interface** — Light, dark, and Glass themes with transparency and live background blur.
- **⚙️ Live settings** — Customize popup appearance, font sizes, blur, and layout with immediate visual feedback.
- **📥 Import & export** — Transfer and back up your snippet collection.
- **🖥️ System tray integration** — Optional Windows startup and background operation.

## 🚀 Getting started

Download TemplatePilot from the **[latest GitHub release](https://github.com/UncleRiot/TemplatePilot/releases/latest)**.

Launch the application, create your first text snippet, assign it to a category, and configure your preferred global shortcut under **Settings**.

Press the shortcut from your target application, search for your snippet, and select **Insert**.

**Requirements:** Windows 10 or later and the .NET 8 Desktop Runtime (unless included in the release package). Some Glass effects depend on Windows support.
